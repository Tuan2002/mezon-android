# Naming and package layout

Root package: **`com.mezon.mobile`**. Mirror the existing tree under `app/src/main/java/com/mezon/mobile/`.

## Types

| Kind | Convention | Notes |
|------|------------|--------|
| Screen | `*Fragment` extends **`BaseFragment`** | Examples: `ChatFragment`, `MessagesFragment`. Not AndroidX `Fragment`. |
| App-level services / caches | `*Controller` | `@Singleton` Hilt types: `ChatController`, `DialogsController`, `ChannelController`, … |
| Auth / push-style boundaries | `*Repository` | e.g. `AuthRepository`, `FcmRepository` — use sparingly; domain state usually lives on controllers. |
| Proto REST models | `com.mezon.mezon.api.*` | Generated / Kotlin DSL from `:core-proto`. |
| Proto realtime | `com.mezon.mezon.rtapi.*` | WebSocket `Envelope` payloads and send helpers. |
| DB | Room entities + `*Dao` in **`data/db/`** | Follow existing entity and DAO naming. |
| Reusable custom views | Under **`ui/cells/`** or feature-local | Cells typically extend **`BaseCell`** or related patterns. |

## Members and IDs

- **Notification events**: `camelCase` vals on `NotificationCenter` companion (`dialogsNeedReload`, `messagesDidLoad`). Delegate callback name stays **`didReceivedNotification`** — match existing spelling for consistency with observers.
- **Logging**: `private const val TAG = "ClassName"` near top of file when logging is used.
- **Channel/stream constants**: Reuse existing constants in **`network/`** package (e.g. `CHANNEL_TYPE_*`, `STREAM_MODE_*`) instead of inventing parallel enums.

## Dependency injection

- Controllers and singletons: **`@Singleton`** + **`@Inject constructor`**.
- Fragments: dependencies via **`FragmentEntryPoint`** and **`entryPoint()`** after `inject(context)` — do not thread raw singletons through constructors for `BaseFragment` subclasses.

Match naming of neighboring files in the same package; prefer consistency over renaming legacy outliers unless explicitly refactoring.
